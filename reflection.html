My Reflection

Reflecting on what I have learned, my strongest skill and where I want to improve.

During this module, I have developed a better understanding of what it means to present myself as an aspiring IT professional. I have learned that developing technical skills is important, but it is also important to show these skills professionally. Creating projects, using GitHub and building this portfolio have helped me understand how I can create evidence of the skills that I am developing.

One of the areas in which I currently feel strongest is Java programming. Through my programming projects, I have gained experience working with classes, methods, variables, validation and object-oriented programming concepts. I have also learned how unit testing can be used to check whether different parts of an application are producing the expected results. Although I still have a lot to learn, I am becoming more confident when reading, writing and troubleshooting Java code.

One skill I would particularly like to improve is web development. Creating this portfolio has introduced me to the importance of designing websites that are clear, professional and easy to navigate. I would like to improve my knowledge of HTML, CSS and JavaScript so that I can eventually develop more advanced and interactive websites.

To develop this skill, I plan to practise by creating small web development projects and using online learning resources. I also want to use GitHub to store these projects so that I can track my progress over time. Regular practice will allow me to apply what I learn instead of only understanding the theory.

This portfolio can support my future studies and career because it provides one place where I can demonstrate my development as an IT student. As I complete more projects, I can continue adding them to the portfolio together with new skills, qualifications and achievements. When I eventually apply for internships or employment, potential employers will be able to view examples of my work instead of only reading about my skills on a CV. I therefore see this portfolio as something that can continue developing alongside my IT career.
